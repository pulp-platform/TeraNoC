Endpoint traffic — whole system

Totals for the selected time window, across all groups, tiles and endpoint ports. Group, Network and Sub-NoC selectors do not filter these totals. mst_resp counts responses received at requesting tiles; slv_resp counts responses sent from serving tiles, on remote ports.

Effective multicast/reuse factor = mst_resp / slv_resp (ratio of summed response handshakes). Includes MSHR fan-out and cached reuse; this is not a pure multicast fan-out count. Window ratios can also reflect in-flight responses crossing window boundaries. Benchmark ratio uses the recorded benchmark windows.

Endpoint totals aggregate tiles and groups; these are distinct from directional links. Older traces omit mst_req and slv_req; these are unavailable, not zero. Updated probes collect both request and response endpoint handshakes. Directional request-link counters above are collected separately; multi-hop link counts cannot recover endpoint totals.
